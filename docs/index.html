QuimeraReader

A comprehensive, self-hosted platform designed for managing massive ebook (EPUB) and audiobook libraries with AI-powered synchronization.

View on GitHub Installation

🎙️ AI Read-Along Sync

Utilizes local Whisper.net AI to generate synchronization maps, actively highlighting the EPUB text as the audiobook plays. A seamless, immersive experience.

⚡ Clean Architecture

Built entirely on a 100% C# .NET 10 ecosystem following strict Clean Architecture and CQRS principles. High performance, modular, and maintainable.

📚 Automated Library Management

Background scanners automatically detect, process, and scrape metadata for dropped EPUBs and Audiobooks from Hardcover, Google Books, and OpenLibrary.

Docker Deployment (Recommended)

QuimeraReader is distributed as a multi-stage Docker container via GitHub Container Registry. Mount your media, library, and config volumes to get started.

docker run -d \
  --name=quimerareader \
  -p 5000:5000 \
  -v /path/to/downloads:/media \
  -v /path/to/library:/library \
  -v /path/to/config:/config \
  ghcr.io/tomas-falcon/quimerareader:latest

For the complete docker-compose.yml and advanced configuration, please check the GitHub Repository.
